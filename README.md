# AlifBa — Арабский алфавит

Приложение для изучения арабского алфавита. Работает как PWA — можно установить на телефон.

## Файлы

- `index.html` — главная страница
- `manifest.json` — PWA манифест
- `sw.js` — сервис воркер (офлайн режим)
- `icon.svg` — иконка приложения

## Деплой на Vercel

1. Загрузи эту папку на GitHub
1. Зайди на vercel.com → New Project → выбери репо
1. Настройки оставь по умолчанию → Deploy
1. Получи ссылку и скинь семье!

## Установка на телефон

**iPhone:** Safari → Поделиться → На экран Домой  
**Android:** Chrome → ⋮ → Добавить на главный экран
